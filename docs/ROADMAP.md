# Roadmap

EDITH is an early development milestone, not a production-certified assistant.

## Completed Foundation

- Native EDITH conversational TUI
- LM Studio and Ollama local model routing
- OpenCode, Codex, and Claude Code adapters
- MCP client/server foundation
- General web search, official-source search, documentation lookup, and fetch
- Google Workspace OAuth and personal connectors
- GitHub/GitLab context
- Personal briefing engine
- Security and confirmation policy foundation

## Near Term

- Improve packaging and installation flows
- Add richer integration tests for live connectors
- Improve policy UX for confirmation-gated writes
- Add configuration commands for optional search providers
- Harden OpenCode non-interactive result contracts where upstream interfaces allow

## Later

- Voice adapter
- Desktop/mobile/API interfaces
- More personal assistant workflows
- OpenClaw integration
- Optional self-hosted search deployment guidance

## Not Yet Declared

- Project license
- Stable public API
- Production support guarantees
