# Security Policy

## Reporting Vulnerabilities

Do not publish suspected vulnerabilities as public GitHub issues.

If GitHub private vulnerability reporting is enabled for this repository, use that channel. If it is not enabled, contact the repository owner privately before disclosing details publicly.

## Sensitive Information

Do not include secrets in reports, issues, pull requests, screenshots, logs, or reproduction repositories.

Sensitive data includes:

- OAuth client secrets
- OAuth access or refresh tokens
- API keys
- passwords
- private keys
- email contents
- calendar contents
- personal documents
- contact data

## Supported Status

EDITH is currently an early development project. Security boundaries exist, but no production support guarantee has been declared.
